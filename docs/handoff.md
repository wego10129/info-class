## 試過但行不通
- 疊在一起的 PR 把 base 設成前一個分支，合併後 base 不一定改回 main。base 一律設 main，依序合併。
- Playwright 對 disabled 的輸入框執行 fill 會等到逾時。
- 測試截圖用相對路徑會存進專案資料夾、被 `git add -A` 提交（PR #25 才刪掉）。截圖一律存 scratchpad 的絕對路徑。
- 自動測試打太快，畫面上很難同時有 2 隻地鼠，放大丸不會出現；要用接近學生的速度（約 3 秒一隻）測。超級木槌會暫停倒數，測試的時間上限要拉長。
- 用 setTimeout 對齊動畫不準（瀏覽器晚約 25 毫秒才開始播）：敲到的時間點要從 `anim.ready` 算起。
- `defeat`、`N = {…}` 這類程式碼在重要按鍵模式也有一份，用字串取代時要先確認只出現一次。
