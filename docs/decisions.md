## 2026-11-08 決定採用引擎＋設定架構，不用 ES modules，產出教師下載版與學生網址版

- **決定**
  - 玩法相同的遊戲共用一份「引擎」，各遊戲只放自己的「設定」。
  - 共用程式用一般 `<script src>` 載入，不用 ES modules（`import`／`export`）和 `fetch()`。
  - 同一份程式產出兩種版本：教師下載版（從檔案直接開）、學生網址版（GitHub Pages）。
- **為什麼**
  - 現在有好幾頁幾乎一樣，例如：
    - typing-ninja.html、punctuation.html、keyboard-hero.html 只差兩行
    - keyboard-w1～w3.html 也只差兩行
  - 改一個地方要改好幾個檔案，容易漏改。
  - 教師下載版要能直接用瀏覽器打開 `.html` 檔，這種開法不能用 ES modules 和 `fetch()`。
- **影響範圍**：全站。依 CLAUDE.md 的「目標結構」分階段搬遷，舊網址與網址參數不可失效（見 docs/url-contract.md）。
- **狀態**：已採用（第 0 階段：打地基，只建文件）

## 2026-11-08 學生名字可以存在學生電腦，不可以存到公開網頁

- **決定**
  - 學生輸入的名字可以存在學生電腦瀏覽器的 localStorage。
  - 名字不可以存到 GitHub 或任何公開網頁。
- **為什麼**：學生不小心關掉網頁時，紀錄（包括名字）不會全部消失，不用重打。
- **影響範圍**
  - typing-ninja.html、punctuation.html、keyboard-hero.html：`nm=1` 時，名字存在 `前綴sess`。
  - words.html：2026-11-09 起也把名字存在 `words1_sess`。以前只存號碼，學生每次都要重打名字。
  - 四個教師設定頁的說明改成「名字會存在這台電腦的瀏覽器……電腦還原時才會刪除；不會上傳到網路」（2026-11-09）。
- **狀態**
  - 行為：已採用，現在的程式就是這樣。
  - 已改正：程式註解「姓名只留在畫面上，不儲存」已改成實際做法（2026-11-08）。

## 2026-11-09 字母流星雨（英文）難度調整

- **決定**
  - **掉落距離拉長**：流星畫小一點，從畫面最上面一直掉到草地中間，不是停在草地上緣。1366×768 的螢幕上，距離從 184px 變成 265px。
  - **秒數依距離放大 1.4 倍**，所以看起來的速度和以前差不多，學生有比較多時間看字母、打字。
  - **字母越多掉得越慢**：每多 1 個字母多給的秒數，新手 1.4→2.2 秒、勇者 1.1→2 秒、大師 1→1.6 秒（還要再乘 1.4）。

    - 同時 2 顆流星：從第 4 小關開始，改成只在第 5 小關。
- **為什麼**：老師回報勇者一次出現 3 個字母，三年級學生很吃力，和新手的難度差太多。
- **影響範圍**

- **狀態**：已完成（2026-11-09）。

## 2026-11-10 流星一出現，字母就要看得到

## 2026-11-10 隱藏關「危機！流星群襲來」降低門檻：雙子流星
