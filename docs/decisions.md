# 決策紀錄

重要的決定記在這裡，新的往下加。每一筆寫：日期、決定了什麼、為什麼、影響範圍、狀態。
狀態用：**已採用**（已經照這樣做）、**待實作**（決定了，程式還沒改）。

## 2026-11-08 決定採用引擎＋設定架構，不用 ES modules，產出教師下載版與學生網址版

- **決定**
  - 玩法相同的遊戲共用一份「引擎」，各遊戲只放自己的「設定」。
  - 共用程式用一般 `<script src>` 載入，不用 ES modules（`import`／`export`）和 `fetch()`。
  - 同一份程式產出兩種版本：教師下載版（從檔案直接開）、學生網址版（GitHub Pages）。
- **為什麼**
  - 現在有好幾頁幾乎一樣，例如：
    - typing-ninja.html、punctuation.html、keyboard-hero.html 只差兩行
    - keyboard-w1～w3.html 也只差兩行
  - 改一個地方要改好幾個檔案，容易漏改。
  - 教師下載版要能直接用瀏覽器打開 `.html` 檔，這種開法不能用 ES modules 和 `fetch()`。
- **影響範圍**：全站。依 CLAUDE.md 的「目標結構」分階段搬遷，舊網址與網址參數不可失效（見 docs/url-contract.md）。
- **狀態**：已採用（第 0 階段：打地基，只建文件）

## 2026-11-08 學生名字可以存在學生電腦，不可以存到公開網頁

- **決定**
  - 學生輸入的名字可以存在學生電腦瀏覽器的 localStorage。
  - 名字不可以存到 GitHub 或任何公開網頁。
- **為什麼**：學生不小心關掉網頁時，紀錄（包括名字）不會全部消失，不用重打。
- **影響範圍**
  - typing-ninja.html、punctuation.html、keyboard-hero.html：`nm=1` 時，名字存在 `前綴sess`。
  - words.html：2026-11-09 起也把名字存在 `words1_sess`。以前只存號碼，學生每次都要重打名字。
  - 四個教師設定頁的說明改成「名字會存在這台電腦的瀏覽器……電腦還原時才會刪除；不會上傳到網路」（2026-11-09）。
- **狀態**
  - 行為：已採用，現在的程式就是這樣。
  - 已改正：程式註解「姓名只留在畫面上，不儲存」已改成實際做法（2026-11-08）。

## 2026-11-08 沒有設定領獎時間（end）時，全部通關才能領獎狀

- **決定**：網址沒有 `end` 的時候，學生要全部通關才能領獎狀。有領獎狀功能的頁面都適用這條規則。
- **「全部通關」怎麼算**（老師 2026-11-09 確認）
  - typing-ninja.html、punctuation.html、keyboard-hero.html：每個有開的關卡都達到「打開下一關」的標準：
    - 第一關完成 3 次
    - 第二關：英文三個小關都玩過；標點、按鍵拿到 3 顆星
    - 打敵人的關卡（流星雨、忍者、病毒）打通最高一級
    - 第四關（魔王戰、影子賽車）全部過關
  - 星星拿滿、全程制霸是**隱藏成就**，不算在全部通關的條件裡。拿到的話，獎狀等第照樣會變高。
  - words.html：每個題庫的第二關都拿到 1 顆星以上（60 分）。
- **教師設定頁**（老師 2026-11-09 決定）：四個設定頁都加一個勾選「全部關卡都過關才能領獎狀（不看時間）」。勾選後產生的連結不帶 `end`。
- **改以前**
  - typing-ninja.html、punctuation.html、keyboard-hero.html：沒有 `end` 時，11:50 起可以領。
  - words.html：沒有 `end` 時，隨時可以領。
- **影響範圍**
  - 沒有 `end` 的舊連結：改成全部通關才能領。
  - 有 `end` 的連結：完全不變。
  - 用到的頁面：typing-ninja.html、punctuation.html、keyboard-hero.html、words.html、keyboard.html、typing-setup.html、punct-setup.html、words-setup.html，以及之後新增、有領獎狀功能的遊戲。
- **狀態**：已完成（2026-11-09）。

## 2026-11-09 字母流星雨（英文）難度調整

- **決定**
  - **掉落距離拉長**：流星畫小一點，從畫面最上面一直掉到草地中間，不是停在草地上緣。1366×768 的螢幕上，距離從 184px 變成 265px。
  - **秒數依距離放大 1.4 倍**，所以看起來的速度和以前差不多，學生有比較多時間看字母、打字。
  - **字母越多掉得越慢**：每多 1 個字母多給的秒數，新手 1.4→2.2 秒、勇者 1.1→2 秒、大師 1→1.6 秒（還要再乘 1.4）。
  - **勇者變簡單，和新手接得上**：
    - 字母數：五個小關從 1～2、2、2～3、3、3 個，改成 1～2、1～2、2、2～3、2～3 個。
    - 同時 2 顆流星：從第 4 小關開始，改成只在第 5 小關。
- **為什麼**：老師回報勇者一次出現 3 個字母，三年級學生很吃力，和新手的難度差太多。
- **影響範圍**
  - 只改英文的字母流星雨。打字忍者、標點忍者、病毒來襲的設定都不變。
  - 程式放在 typing-ninja.html、punctuation.html、keyboard-hero.html 共用的 `METEOR_TUNE`、`METEOR_LAND`、`METEOR_SLOW`，三個檔案仍然只差兩行。
  - 紀錄的鍵名、通關條件（打碎 15／30／50 顆）都不變。
- **狀態**：已完成（2026-11-09）。

## 2026-11-09 字母流星雨：字母越多，掉得明顯越慢

- **決定**
  - 每多 1 個字母多給的秒數再加大：新手 2.2→3.6 秒、勇者 2→3.2 秒、大師 1.6→2.6 秒（還要再乘 1.4）。
  - 一個字母的流星秒數不變。
  - 結果（1366×768，掉落 266px）：勇者第 1 小關一個字母 7 秒、兩個字母 7→11.5 秒；第 4 小關三個字母 11.2→14.6 秒。兩個字母的流星大約只剩一個字母的六成速度。
- **為什麼**：老師試玩上一版，兩個字母和一個字母的流星掉得差不多快；一個字母的流星如果再加快，學生會太吃力，所以改成讓字母多的流星變慢。
- **影響範圍**
  - 只改英文的字母流星雨（`METEOR_TUNE` 的 `per`），三個共用檔案一起改。字母數、同時幾顆、通關條件、紀錄都不變。
- **撤銷方式**：在 GitHub 這個 PR 按「Revert」。
- **狀態**：已完成（2026-11-09）。

## 2026-11-10 英文改回大寫顯示，大小寫都算對

- **決定**
  - 英文的題目、流星上的字、打字欄位、影子賽車的字，都改回大寫顯示（鍵帽本來就是大寫）。
  - 學生打大寫、小寫都算對，不管大寫燈有沒有開。
  - 拿掉「大寫燈亮著就暫停、跳出提醒」和「打出大寫字母不算」。
  - 重要按鍵練習裡 Caps Lock 的情境題保留（那是教按鍵用途，和英文打字分開）。
- **為什麼**：學生反映大寫比較看得懂，多數出版社也用大寫。2026-11-03 改成小寫，是因為題目大寫時學生會先按 Caps Lock，再被大寫燈提醒擋住；現在大小寫都算對，就不用再擋。
- **以後**：做英文單字、英文名字的打字練習時，那個練習才要分大小寫，進入前另外說明「留意大小寫」。
- **影響範圍**：只影響英文（typing-ninja.html）；三個共用檔案一起改，仍然只差兩行。紀錄、網址參數都不變。
- **撤銷方式**：在 GitHub 這個 PR 按「Revert」。
- **狀態**：已完成（2026-11-10）。

## 2026-11-10 英文隱藏關「危機！流星群襲來」

- **決定**
  - 字母流星雨「大師」通關後打開。第一次通關大師時跳出邀請視窗（挑戰／回到關卡選單），只跳一次；之後在關卡選單「大師」下面多一個按鈕，隨時可以玩。還沒打開時不顯示。
  - 生存挑戰：3 條命，扣完就結束，記錄「最多打碎幾顆」。
  - 每顆流星 1～4 個字母（隨機）；秒數用大師的算法再乘 0.75～0.85（快 15～25%）。
  - 每打碎 10 顆進下一波：第 1～5 波同時最多 2、2、3、3、3 顆；第 5 波以後每一波再快 5%（這一項最多快到 0.6 倍）。鍵帽沒有字（同大師）。
- **為什麼**：老師希望大師後有隱藏關卡；老師選了「快 15～25%」（原本 0.3～0.5 秒太小，學生感覺不到）和「生存挑戰」。
- **影響範圍**
  - **紀錄格式新增欄位**（老師 2026-11-10 同意）：英文的練習紀錄多一個 `crisis`（plays、best、bestKills、asked、hist）。鍵名不變；舊紀錄沒有這個欄位時自動補上預設值，舊的欄位都不動。標點、重要按鍵的紀錄不加。
  - 獎狀、稱號、隱藏成就、全部通關的條件都不變。
  - 三個共用檔案一起改，仍然只差兩行。
- **撤銷方式**：在 GitHub 這個 PR 按「Revert」。已經存進學生電腦的 `crisis` 欄位會留著，但不會影響其他功能。
- **狀態**：已完成（2026-11-10，老師同意後合併）。

## 2026-11-09 隱藏成就只給大方向提示

- **決定**
  - 「星星拿滿」「每一級都通關」「無傷打敗魔王」是**隱藏成就**，關卡選單不再直接寫出達成條件和稱號。
  - 學生全部通關以後，才出現「🔍 好像還有隱藏成就唷！大方向：…」。
    - 大方向例如「每一關都拿 5 顆星」「一條命都不扣，打敗魔王」。
    - 只列出還沒做到的項目。
  - 做到了才揭曉稱號，例如「已經是『完美傳奇勇者』！」。
- **為什麼**：讓已經全部通關的學生還有探索的目標，也不會在一開始就被太難的條件嚇到。
- **影響範圍**：typing-ninja.html、punctuation.html、keyboard-hero.html 的關卡選單提示文字。獎狀等第的算法不變。
- **狀態**：已完成（2026-11-09）。
