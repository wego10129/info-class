## 2026-11-08 決定採用引擎＋設定架構，不用 ES modules，產出教師下載版與學生網址版

- **決定**
  - 玩法相同的遊戲共用一份「引擎」，各遊戲只放自己的「設定」。
  - 共用程式用一般 `<script src>` 載入，不用 ES modules（`import`／`export`）和 `fetch()`。
  - 同一份程式產出兩種版本：教師下載版（從檔案直接開）、學生網址版（GitHub Pages）。
- **為什麼**
  - 現在有好幾頁幾乎一樣，例如：
    - typing-ninja.html、punctuation.html、keyboard-hero.html 只差兩行
    - keyboard-w1～w3.html 也只差兩行
  - 改一個地方要改好幾個檔案，容易漏改。
  - 教師下載版要能直接用瀏覽器打開 `.html` 檔，這種開法不能用 ES modules 和 `fetch()`。
- **影響範圍**：全站。依 CLAUDE.md 的「目標結構」分階段搬遷，舊網址與網址參數不可失效（見 docs/url-contract.md）。
- **狀態**：已採用（第 0 階段：打地基，只建文件）

## 2026-11-08 學生名字可以存在學生電腦，不可以存到公開網頁

- **決定**
  - 學生輸入的名字可以存在學生電腦瀏覽器的 localStorage。
  - 名字不可以存到 GitHub 或任何公開網頁。
- **為什麼**：學生不小心關掉網頁時，紀錄（包括名字）不會全部消失，不用重打。
- **影響範圍**：typing-ninja.html、punctuation.html、keyboard-hero.html（`nm=1` 時，名字存在 `前綴sess`）。
- **狀態**
  - 行為：已採用，現在的程式就是這樣。
  - 已改正：程式註解「姓名只留在畫面上，不儲存」已改成實際做法（2026-11-08）。

## 2026-11-08 鍵盤小勇士（keyboard-w1～w3）保留並比照新的派發方式

- **決定**
  - `#student`、`#demo` 要繼續支援。
  - 練習紀錄存在 localStorage，關掉瀏覽器還在；只有電腦還原（或老師按清除）才會刪掉。
  - 之後比照其他遊戲：先在教師設定頁設定，再產生學生連結或下載捷徑檔來派發。
- **為什麼**
  - 已經發出去的舊連結要能用。
  - 學生不小心關掉網頁，紀錄也不會消失。
- **影響範圍**：keyboard-w1.html、keyboard-w2.html、keyboard-w3.html、keyboard.html。
- **狀態**
  - 紀錄保存：已採用，現在的程式就是這樣。
  - 待實作：教師設定頁先設定，再產生連結或下載捷徑檔（現在沒有地方會產生 `#student`）。
  - 已改正：程式註解「只存這個分頁；關掉分頁就清空」（2026-11-08）。

## 2026-11-08 沒有設定領獎時間（end）時，全部通關才能領獎狀

- **決定**：網址沒有 `end` 的時候，學生要全部通關才能領獎狀。有領獎狀功能的頁面都適用這條規則。
- **現況**
  - typing-ninja.html、punctuation.html、keyboard-hero.html：沒有 `end` 時，11:50 起可以領。
  - words.html：沒有 `end` 時，隨時可以領。
- **影響範圍**
  - 只影響沒有 `end` 的連結。教師設定頁從 2026-11-02 起都會產生 `end`，所以主要是更早發出的舊連結。
  - 用到的頁面：typing-ninja.html、punctuation.html、keyboard-hero.html、words.html，以及之後新增、有領獎狀功能的遊戲。
- **狀態**：待實作。

## 2026-11-08 重要語詞的縣市一律要打正式寫法「臺」

- **決定**
  - 「台」不算對，一律要打正式寫法「臺」。
  - 教師設定頁拿掉「台、臺都算對」的勾選。
- **現況**
  - words.html：網址沒有 `tw=0` 時，「台」「臺」都算對。
  - words-setup.html：「台、臺都算對」預設是勾的。
- **影響範圍**
  - words.html、words-setup.html、words-data.js（註解）。
  - 沒有 `tw` 的舊連結，會從「都算對」變成「一定要打臺」。
  - 有 `tw=0` 的舊連結結果不變。
- **狀態**：已完成（2026-11-08）。設定頁的勾選已拿掉，學生頁不再把「台」當成「臺」，`tw` 參數不再有作用。words.html、words-data.js 的註解也一起改正了。
